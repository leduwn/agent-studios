## 1. Problem Statement & Root Cause

Unified Git patches generated by tools often contain both regular text file modifications and binary file changes in a single contiguous patch stream.

Prior implementation suffered from two key limitations:
1. **Binary All-or-Nothing Suppression**: When any binary file was detected in summary (`binary_files.length > 0`), the client flagged `isBinary: true` and cleared `text = ''`. This made human-readable text hunks for accompanying source files completely invisible in the review workbench.
2. **Git C-style Octal Path Corruption**: Git escapes non-ASCII characters (and paths with spaces) inside double quotes using C-style octal byte escapes (e.g. `"\341\273\207"` for `ệ`). Parsing these literally caused file paths to show garbled raw octal sequences in the UI file tree.
3. **Unclassified Patch Dropping**: Non-git unified diffs or raw patch snippets lacking standard `diff --git` headers were dropped rather than rendered.

---

## 2. Technical Implementation

### A. Non-Fatal Text Decoding across Contiguous Buffers
In `src/bridge/ipc/ArtifactClient.ts`, decoding the accumulated raw buffer now uses `new TextDecoder('utf-8', { fatal: false })`:
- Decodes all text hunks cleanly without crashing on embedded binary bytes.
- Leaves `isBinary: true` based on metadata or binary markers so UI indicators reflect binary contents.
- Retains `rawBuffer: fullBuffer` verbatim so file exports and SHA-256 verification maintain byte-for-byte fidelity.

### B. Octal UTF-8 Git Path Unquoting
In `src/cards/DiffParser.ts`, added `unquoteGitPath(str)`:
- Detects quoted paths `^"(.*)"$`.
- Replaces octal sequences (`\nnn`) with parsed byte buffers and standard escape sequences (`\n`, `\t`, `\"`, `\\`).
- Decodes the assembled byte array via UTF-8, restoring diacritics (such as Vietnamese `tài liệu.txt`) accurately.

### C. Unclassified Diff Fallback
In `src/cards/DiffParser.ts`:
- Added `'unknown'` to `FileChangeKind`.
- If no `diff --git` headers match but patch content contains hunks or lines, creates a fallback file node labeled `'RAW-DIFF (Unclassified)'` with `changeKind: 'unknown'`.
